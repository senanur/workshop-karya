# Repo notes

## Git remote

This repo has two remotes; use **`github`** as the primary remote to push to
and pull from (`https://github.com/senanur/workshop-karya.git`). `origin`
points at a Bitbucket repo that's stale (stuck at the initial-import commit)
and not kept in sync — don't push there unless explicitly asked to.

```
git push github main
```
